# Formulations
This folder contains a series of example models for [ONELAB](https://onelab.info/) finite element software (comprised of [Gmsh](https://gmsh.info/) and [GetDP](https://getdp.info/)). The main goal is to show a few multi-disciplinary formulations (see [formulations.pdf](./formulations.pdf)) and how they can be implementated in ONELAB.
